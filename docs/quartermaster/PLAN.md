# Fork maintenance

Maintain compatibility with native coding clients and their user-selected providers.

| ID    | Outcome                                                   | Acceptance                                                                                     |
| ----- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| F-001 | Track the upstream source and maintain a reviewable fork. | Record the upstream commit, preserve fork changes and pass the affected checks on each update. |

The integration branch is `main`. Update it through pull requests. Inspect changes to workflows, permissions and distribution separately before releasing any binaries.
